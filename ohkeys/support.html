App 简介

在一个 App 里轻松查看你各类大模型 API Key 的余额与用量。支持多家服务商、多语言、本地加密存储。

如何使用

  1. 打开 App → 点右下角「+」→ 选择内置服务商，或填写自定义 Base URL。
  2. 粘贴你的 API Key → 保存后自动查询余额 / 用量。
  3. 部分服务商未提供余额接口时，会如实提示「暂不支持」。
  4. 可在设置中调整自动刷新频率、语言与显示选项。

常见问题

Q：会不会上传我的 API Key？

不会。Key 仅保存在你的设备本地（加密存储）。查询请求由你的设备直接发往你配置的服务商；我们没有服务器、不经手中转。

Q：怎么保护余额隐私？

使用 iOS 18 及以上系统时，可长按本 App 图标 → 选择「需要面容 ID」，用系统面容锁保护整个 App。本 App 自身不索取面容权限。

Q：为什么某个服务商显示「暂不支持」？

该服务商未提供可用的余额 / 用量接口。

Q：怎么删除我的数据？

在 App 内删除卡片，或卸载 App。

Support · Oh Keys

Support Center

About

Check the balance and usage of your LLM API keys across multiple providers — all in one app. Secure local storage, multi-language.

How to use

  1. Open the app → tap "+" → pick a built-in provider or enter a custom Base URL.
  2. Paste your API key → the balance/usage is queried automatically.
  3. If a provider has no public balance API, the app will clearly say "not supported".
  4. Adjust auto-refresh, language and display options in Settings.

FAQ

Q: Does the app upload my API key?

No. Keys are stored only on your device (encrypted). Requests go directly from your device to the provider you configure; we run no server and never relay them.

Q: How can I protect my balance privacy?

On iOS 18+, long-press the app icon and choose "Require Face ID" to lock the whole app with the system. The app itself does not request Face ID permission.

Q: Why does a provider show "not supported"?

That provider does not expose a usable balance/usage API.

Q: How do I delete my data?

Delete cards inside the app, or uninstall the app.
