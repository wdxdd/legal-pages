隐私政策 · Oh Keys（大模型余额助手）

更新日期：2026-09-26 ｜ 生效日期：发布之日

1. 概述

「Oh Keys（大模型余额助手）」（下称"本 App"）是一个运行在你设备本地的工具，用于查询你自行填写的第三方大模型服务商 API Key 的余额与用量。本 App 没有账号体系，也没有由我们运营的服务器；我们不收集、不上传、不共享你的任何个人信息。

2. 我们如何处理你的数据

  • API Key 与卡片信息：你输入的 API Key、卡片名称、备注等，仅保存在你的设备本地（iOS 使用 Keychain、Android 使用 Keystore 加密存储）。除下述"余额查询"外，不会上传到我们或任何无关第三方。
  • 余额 / 用量查询：当你在 App 内发起查询（含你开启的定时刷新）时，App 会从你的设备直接向你配置的第三方大模型服务商接口发送请求，并在请求中携带你的 API Key 以完成鉴权。该请求由你的设备与服务商点对点完成，我们不经手、不中转、不记录。服务商如何处理该请求，适用其各自的隐私政策。
  • 我们不收集：不收集设备标识、位置、通讯录、照片、麦克风、广告标识等；App 内不含第三方广告或数据分析 SDK。

3. 数据存储与保留

  • 你的数据仅存储在你的设备上；卸载 App 即随之删除。
  • 我们无服务器，因此不存在"服务器端保留期"。

4. 网络与后台任务

  • App 仅在"你主动发起查询"或"你开启的自动刷新（前台/后台定时，最小间隔约 60 分钟）"时联网，不用于广告或追踪。
  • 你可随时在 App 设置中关闭自动刷新。

5. 权限说明

  • 网络：用于你发起的余额 / 用量查询。
  • iOS：未使用面容 ID / 定位 / 麦克风 / 相册等敏感权限。
  • Android：可能使用"后台任务"能力用于定时刷新，可在系统设置中关闭。

6. 未成年人

本 App 面向成年开发者与用户，不针对儿童，不收集儿童信息。

7. 你的控制权

你可在 App 内随时删除卡片 / Key、关闭自动刷新，或卸载 App 以清除本地数据。

8. 政策变更

Privacy Policy · Oh Keys

Last updated: 2026-09-26 ｜ Effective: on release

1. Overview

"Oh Keys" (the "App") is a tool that runs locally on your device to check the balance and usage of third-party LLM API keys that you enter yourself. The App has no account system and no server operated by us; we do not collect, upload, or share any of your personal information.

2. How we handle your data

  • API keys and card info: API keys, card names, and notes you enter are stored only on your device (encrypted via iOS Keychain / Android Keystore). Except for the balance queries below, they are never uploaded to us or to any unrelated third party.
  • Balance / usage queries: When you trigger a query (including your enabled periodic refresh), the App sends a request directly from your device to the third-party LLM provider endpoint you configured, carrying your API key for authentication. This request is made point-to-point between your device and the provider; we do not proxy, relay, or log it. The provider's handling of that request is governed by their own privacy policy.
  • What we do NOT collect: no device identifiers, location, contacts, photos, microphone, or advertising identifiers; the App contains no third-party ads or analytics SDKs.

3. Storage and retention

  • Your data stays on your device; uninstalling the App removes it.
  • We run no server, so there is no server-side retention.

4. Network and background

The App uses the network only for queries you initiate or for the periodic refresh you enable (foreground/background, minimum interval ≈ 60 minutes). It is never used for advertising or tracking.

5. Permissions

  • Network: for your balance/usage queries.
  • iOS: no Face ID / location / microphone / photo permissions are used.
  • Android: a background task capability may be used for periodic refresh; you can disable it in system settings.

6. Children

The App targets adult developers and users, not children, and does not collect children's data.

7. Your control

You can delete cards/keys, disable auto-refresh, or uninstall the App at any time.

8. Changes

If this policy changes, we will update this page and the "Last updated" date.
